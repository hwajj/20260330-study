# study-session-start

SSOT: `STUDY-PLAN-8W.md` (repo root `20260330-study`).  
코테 실행 상세(문제 이름·요일): [`PS-TRACK-8W.md`](../../PS-TRACK-8W.md) — 있으면 **쉬운 말**로만 가져온다.

## 0. 말투 (필수)

사용자에게 **먼저** 쉬운 블록을 쓴다. 플랜 용어는 그 다음(짧게)만.

| 하기 | 하지 않기 |
|------|-----------|
| 짧은 문장, 일상어 («종이로 풀기», «코드 치지 않기») | invariant, trace, SSOT, 슬롯만 던지기 |
| 오늘 **3~5개 체크** — «회사 / 코테 / 저녁» 구분 | 커리큘럼 파일 목록 길게 벽돌 |
| 코테: **문제 이름 + 오늘 뭐 하면 됨** (수=종이, 금=코드) | §4-C 문단만 복사 |
| `CURRENT_WEEK` 등은 **한 줄** (맨 아래 «플랜 커서») | 응답 맨 위에 커서·§4-B부터 시작 |

**코테 한 줄 규칙:** «많이 안 풀어요. 이번 주 1~2문제. 수요일=종이만, 금요일=코드. 저녁 90분은 FE 손코딩이랑 따로.»

## 1. 파일 읽기

`STUDY-PLAN-8W.md`에서 다음을 읽는다.

- 상단 **`CURRENT_WEEK`**, **`CURRENT_DAY`**, **`CURRENT_CURR_WEEK`**, **`CURRENT_CURR_DAY`**
- **§4-B** — 해당 주(W) 행의 ☐/☑
- **§4-A** — `### Week {N}` 블록 (주 목표, 금요 통과, 요일 표, 「주말:」 줄)
- **§3** — 회사 구간 (커리큘럼·리딩)
- **§2** — 저녁 타임블록·AI 규칙 (요약용)
- **§4-C** — 오늘 요일에 맞는 **사고력 슬롯** + 해당 주 「사고력」 한 줄 (§4-A Week 블록)
- **§10** — `막힌 질문`, `마지막 세션` (있으면 답변에 반영)

[`CURRICULUM-FULL-TRACK.md`](../../CURRICULUM-FULL-TRACK.md)에서 **`CURRENT_CURR_DAY`** 행의 **제목**을 찾는다 (오늘 이론 1개).  
`CURRICULUM-BRIDGE-8W.md`는 선택(실무 주차와 겹치는 Day 힌트만).

`PS-TRACK-8W.md`에서 **`## 5. Week {week}`** (또는 해당 주 절)이 있으면 코테 **문제 이름·오늘 요일 행**을 읽는다. 없으면 §4-C 요일 슬롯만으로 쉬운 문장 작성.

## 2. 오늘 요일 결정 (순서)

1. 사용자 메시지에 **Week / 요일**이 있으면 그 요일 사용 (주는 명시 Week, 없으면 `CURRENT_WEEK`).
2. 아니면 `week = CURRENT_WEEK`, `day = CURRENT_DAY`.
3. §4-B에서 `week` 행의 `day`가 이미 ☑이면, **월→화→…→일** 순으로 **첫 ☐**를 `day`로.
4. 해당 주 행이 전부 ☑이면: 주 완료 안내 + §10 완료 ☑ 제안 + `CURRENT_WEEK`+1·`CURRENT_DAY`=월 제안. **§4-A 내용은 출력하지 않고** 여기서 멈춘다.

## 3. §4-A에서 과제 추출

`### Week {week}` 섹션만 파싱한다.

| day | 소스 |
|-----|------|
| 월~금 | 해당 **요일 행**: 회사 (추가), 저녁 90m, 열 파일 |
| 토·일 | **「주말:」** 한 줄 + §1 주말 예산; §4-A 평일 표 행 없음 |

같은 블록의 **주 목표**, **금요 통과**는 «이번 주 끝나면» **한 줄씩**만 쓴다.

## 4. 회사 구간 합치기 (월~금)

- §3: 해당 주 **CURRICULUM-BRIDGE** — 오늘은 **다음으로 읽을 Day 1개 이름**만 (50~80줄 분량이라고 쉬운 말로)
- §4-A **회사 (추가)** + **열 파일** (50~80줄 리딩)

## 5. 출력 형식 (고정)

**한국어.** 위 **§0 말투**를 따른다. 아래 **순서**를 지킨다.

```markdown
## 오늘 공부 — Week {week} · {day} ({날짜})

### 오늘 할 일 (이것만 보면 됨)

1. **이론 (회사, 1~1.5시간)** — `CURRENT_CURR_DAY` **한 편** 읽기 + 노트 3줄 + 면접 질문 1개 말하기 (제목만 쉬운 말로)
2. **회사 코드 읽기** — §4-A 오늘 행 (한 문장). 이론 길면 «내일»
3. **코테 (20~30분, 회사)** — (한 문장: 문제 이름 + 종이만 / 선정만 / 코드). 없으면 «오늘 코테 쉬는 날»
4. **저녁** — (한 문장: 90분 손코딩). **AI 끄는 시간** 표시
5. **참고** — 막힌 질문 / 없으면 «없음»

### 시간표 (필요할 때만)

- 19:15–19:45: …
- 19:45–21:15: **손코딩 (AI 금지)** — …
- 21:30–22:30: 메모·log
- 22:30–23:00: 내일 열 파일 경로 1줄

### 이번 주 한 줄

- 끝나면 할 수 있어야 하는 것: …

### 열어볼 파일

- `경로` — (왜 보는지 5단어 이내)

### AI

- 손코딩 90분: AI 쓰지 않기
- 그 외: 읽기·질문·힌트 1번 OK

### 끝나면 (wrap 할 때)

- 플랜 체크: Week {week} {day} 완료
- 다음 요일: …

---

**플랜 커서:** W{week} · 플랜상 다음 요일 `{CURRENT_DAY}` → 오늘 실행 **{day}** (체크표: {☐|☑})
```

**토·일:** «오늘 할 일» 3줄 정도로 줄인다 (주말 줄 + 코테/손과제만).

**§4-C 요일 → 쉬운 말 치환 (그대로 쓰기):**

| 요일 | 사용자에게 |
|------|------------|
| 월 | 이번 주 코테 문제 **골라서 링크 적기** |
| 수 | 그 문제 **종이로만** 단계 적어 보기 (코드 X) |
| 금 | 같은 문제 **직접 코드** (AI X) |
| 화·목 | 밤에 **어제 종이 다시 보고** 규칙 한 줄 메모 (15분) |
| 토·일 | 가볍게: 변형 또는 입으로 설명 / 복기만 읽기 |

## 6. 하지 않기

- 손코딩 과제 **전체 정답 코드** 제시 (사용자가 AI OFF 전 **뼈대/통과 기준만** 요청할 때만 예외)
- §4-B / 커서를 **사용자 확인 없이** 파일에 쓰지 않음 (start는 **읽기 + 제시**만; 체크는 wrap·사용자 요청 시)
- `CURRENT_WEEK`와 다른 주의 §4-A를 섞지 않음
- 응답을 **옛 형식**(맨 위 «주간 맥락»+§4-C 원문 장문)으로만 내지 않기
