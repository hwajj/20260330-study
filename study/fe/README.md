**파일명:** `{NN}-{slug}.md` — `NN` = slug `day-NN-…`의 **NN** (2자리).  
예: `day-01-http-basics` → `01-day-01-http-basics.md`

| # | slug | 파일 |
|---|------|------|
| 01 | day-01-http-basics | [01-day-01-http-basics.md](./01-day-01-http-basics.md) |
