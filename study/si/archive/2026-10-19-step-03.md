## 정리

### 한 줄
Spring은 **Bean을 컨테이너가 만들고 필요한 곳에 주입**해서 `new` 연결을 없앤다.

### 핵심
- **IoC**: 객체 생성·수명 주기를 프레임워크가 소유
- **DI**: 의존성을 생성자(권장)로 받음 — 테스트·교체 쉬움
- **`@RestController`**: HTTP 어댑터 / **`@Service`**: 트랜잭션·규칙 / **`JpaRepository`**: DB
- **ApplicationContext**: Bean 레지스트리 — 기동 시 그래프 조립

### 패키지 스케치

```
com.study.si
  health / auth / user / order / security
```

### 통과선 스크립트
직접 `new OrderService(new OrderRepository(...))`를 컨트롤러마다 하면 연결이 깨지고 테스트가 어렵다. Bean으로 등록하면 Security·트랜잭션 프록시까지 한 곳에서 붙는다.
