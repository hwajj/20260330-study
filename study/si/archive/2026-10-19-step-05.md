## 정리

### 한 줄
회원 JWT로 신원 확인하고, 주문 CRUD는 **소유자만** 접근한다.

### 규칙
- validation 실패 → 400
- 토큰 없음/위조 → **401**
- 남의 주문 → 404로 숨김 (존재 여부 누설 최소화)
- DB: MySQL(JPA) · 로컬 H2 프로파일

### 엔드포인트 표

| Method | Path | Auth |
|--------|------|------|
| GET | `/api/ping` | no |
| POST | `/auth/register` | no |
| POST | `/auth/login` | no |
| GET/POST | `/api/orders` | Bearer |
| GET/PUT/DELETE | `/api/orders/{id}` | Bearer |

### 통과선 스크립트
이력서·면접에서 README 표를 열고 «회원가입→로그인 토큰→주문 생성» 30초 동선만 말한다.
