## 진행

### 지도 vs 비지도

- **지도:** 정답(레이블)이 있는 데이터로 분류·회귀를 학습한다.
- **비지도:** 레이블 없이 패턴을 찾는다 — 군집·차원 축소 등.

### 과적합과 대응

- **과적합:** train에 과하게 맞춰 **새 데이터(일반화)** 에 잘 안 맞는 상태.
- **대응:** 정규화(regularization), 데이터 확충·증강, **더 단순한** 모델.

### 편향 — 예시 1개

- **정의:** 데이터·모델이 특정 그룹·상황에 **치우쳐** 예측·의사결정이 한쪽으로 기운다.
- **예:** 과거 남성 위주 채용 데이터로 학습한 스크리너 → 여성 지원자에게 동일 역량인데 낮은 합격 점수(대표성·역사적 편향).

### 트리·SVM·앙상블 — 문제에 쓰기

- **의사결정나무:** 결정 경로를 **설명**해야 하는 분류·규칙 추출; 범주형·비선형 경계에도 무난.
- **SVM:** **마진**을 크게 하는 경계; 상대적으로 **소량·고차원**(텍스트 등); 커널로 비선형.
- **앙상블:** 정확도·안정성을 올리고 싶은 분류·회귀 — **bagging**(분산↓, 예: Random Forest) vs **boosting**(편향↓, 예: GBDT).

### 말로 짝짓기 (통과선)

| 문제 유형 | 짝 | 한 줄 |
|-----------|-----|--------|
| 규칙·설명이 필요한 분류 | 의사결정나무 | 왜 이 클래스인지 경로를 말할 수 있음 |
| 소량·고차원 텍스트 분류 | SVM | 마진 큰 경계, 커널로 비선형 |
| 정확도·안정성 최우선 | 앙상블 | 여러 모델을 묶어 오류 감소 |

### 4단 설명 — 과적합

1. **정의:** 학습 데이터에만 과하게 맞고 새 데이터에서는 성능이 떨어지는 상태.
2. **배경:** 모델이 너무 복잡하거나 데이터가 적·노이즈가 많을 때 train loss만 줄이려 할 때 생김.
3. **구성(대응):** regularization, 더 많은·다양한 데이터, 단순 모델, 검증셋·early stopping.
4. **한계:** 너무 단순하면 underfitting; 데이터·라벨 품질이 나쁘면 regularization만으로는 한계.

### 불균형 데이터

- **지표:** accuracy 대신 **precision**(예측 양성 중 진짜 양성), **recall**(실제 양성 중 잡은 비율), 필요 시 **F1**.
- **SMOTE:** 소수 클래스 샘플 **사이를 보간**해 합성 샘플 생성 → 학습 비율 완화. **train에만** 적용( test SMOTE = 누수).

## 메모

| 문제 유형 | 알고리즘 | 한 줄 |
|-----------|----------|--------|
| 설명·규칙이 필요한 분류 | 의사결정나무 | if-else 경로로 설명 |
| 소량·고차원 분류(텍스트 등) | SVM | 마진 최대 + 커널 |
| 정확도·안정성 극대화 | 앙상블 | bagging / boosting |

## 정리

```
머신러닝은 정답(레이블)이 있는 데이터를 이용해 분류나 회귀를 학습하는 지도학습과, 정답 없이 데이터의 패턴을 찾아 군집이나 차원 축소 등을 수행하는 비지도학습으로 나뉘며, 학습 데이터에 지나치게 맞춰져 새로운 데이터에 대한 일반화 성능이 떨어지는 과적합은 모델이 너무 복잡하거나 데이터가 부족·노이즈가 많을 때 발생할 수 있어 정규화, 데이터 확충·증강, 더 단순한 모델, 검증셋과 early stopping 등으로 대응한다. 또한 데이터나 모델이 특정 그룹이나 상황에 치우쳐 예측 결과가 한쪽으로 기우는 편향이 발생할 수 있으며, 예를 들어 남성 중심의 과거 채용 데이터로 학습한 AI가 동일한 역량의 여성 지원자에게 낮은 합격 점수를 주는 경우가 있다. 문제에 따라 알고리즘을 선택할 때는 결과를 if-else 형태의 경로로 설명하거나 규칙을 추출해야 하는 분류에는 의사결정나무를, 데이터가 상대적으로 적고 특성이 많은 텍스트 분류에는 마진을 크게 만드는 SVM을, 여러 모델을 결합해 정확도와 안정성을 높이고 싶을 때는 앙상블을 사용할 수 있으며, 앙상블은 여러 모델을 병렬적으로 결합해 분산을 줄이는 bagging과 이전 모델의 오류를 보완하면서 순차적으로 학습해 편향을 줄이는 boosting으로 나눌 수 있다. 또한 데이터의 클래스 비율이 불균형할 때는 accuracy만으로 성능을 판단하기보다 예측한 양성 중 실제 양성의 비율인 precision과 실제 양성 중 모델이 찾아낸 비율인 recall을 보고 필요하면 둘의 조화평균인 F1을 사용하며, SMOTE는 소수 클래스 데이터 사이를 보간해 새로운 합성 샘플을 만들어 클래스 불균형을 완화하는 방법으로 반드시 학습 데이터에만 적용해야 한다.
```
